# Point-Cloud-Generalization-A-Self-Supervised-Learning-Approach-using-Torque-Clustering
Point cloud generalization has become a cornerstone  of modern 3D computer vision, yet challenges remain in achieving  robust generalization across categories. In this work, we propose  a hybrid pipeline that combines enhanced PointNet embeddings  with a novel Torque Clustering algorithm for unsupervised  representation learning.

We address key preprocessing challenges in the ModelNet40 dataset, including corrupted OFF headers, unstable normalization, and inconsistent point counts. Experimental evaluation was conducted using all 40 classes, the top 20 classes by sample count, and the top 10 classes by sample count, providing insights into the correlation between class balance and clustering quality. Our results demonstrate that torque clustering, paired with a stabilized PointNet backbone, achieves improved Adjusted Rand Index (ARI) and Normalized Mutual Information (NMI) on balanced subsets, while also highlighting the limitations imposed by data imbalance in the full 40-class case. This work underscores the importance of dataset pre-processing and hybrid unsupervised approaches for point cloud generalization.
